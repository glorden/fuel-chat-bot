# VK-бот «где заправиться»

Бот для тематической VK-беседы про заправку топливом: молча читает сообщения беседы, вытаскивает из них структурированные факты по АЗС (что есть в наличии, длина очереди, когда сообщили) и отвечает на вопросы участников этими фактами, явно показывая свежесть данных.

Архитектура — в [ARCHITECTURE.md](ARCHITECTURE.md), статус разработки — в [PROGRESS.md](PROGRESS.md).

## Как это работает

- Бот подключён к сообществу VK как участник беседы с полным доступом к переписке.
- Читает **все** сообщения, но отвечает по правилам из `AUTO_REPLY_ON_QUESTION` (см. ниже).
- По умолчанию классификация/извлечение/резолв станции — на правилах/regex, ответы — на шаблонах (без LLM). Опционально можно включить разбор через бесплатный LLM (Groq) флагом `LLM_ENABLED` — устойчивее к опечаткам и нестандартным формулировкам; при сбое/лимите бот прозрачно откатывается на правила. Текст ответа в любом случае собирается из шаблонов, не LLM — это защита от галлюцинаций.

## Установка

```bash
git clone https://github.com/glorden/fuel-chat-bot.git
cd fuel-chat-bot
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
copy .env.example .env      # затем заполнить значения
```

## Настройка VK

1. В настройках сообщества: **Сообщения → настройки бота** → включить возможности бота → разрешить добавление сообщества в беседы.
2. Сгенерировать токен доступа сообщества с правом «Сообщения» (управление сообществом → работа с API).
3. Добавить сообщество в целевую беседу как обычного участника, затем выдать ему права администратора беседы **или** «полный доступ к переписке» — без этого бот видит только сообщения с явным упоминанием себя.
4. Заполнить `.env`: `VK_TOKEN`, `GROUP_ID`, `ADMIN_ID`.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `VK_TOKEN` | токен доступа сообщества с правом «Сообщения» |
| `GROUP_ID` | числовой ID сообщества |
| `ADMIN_ID` | VK ID администратора (для review нераспознанных станций) |
| `AUTO_REPLY_ON_QUESTION` | `true`/`false` — отвечать ли на вопросы без явного упоминания бота |
| `LLM_ENABLED` | `true`/`false` — использовать ли Groq для классификации/извлечения/резолва станции (по умолчанию `false`) |
| `GROQ_API_KEY` | бесплатный ключ с [console.groq.com](https://console.groq.com) (нужен только если `LLM_ENABLED=true`) |
| `LLM_MODEL` | модель Groq, по умолчанию `llama-3.3-70b-versatile` |
| `LLM_TIMEOUT_SECONDS` | таймаут запроса к Groq в секундах, по умолчанию `10` |
